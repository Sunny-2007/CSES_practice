# CSES Problem Set 解題筆記

每一題一個資料夾，依 CSES 分類放置：

```
<分類>/<題號>_<題名>/
├── <題號>_<題名>.cpp   # 我自己的解法（保留原始手刻的寫法）
└── ai_optimized.cpp     # AI 協助重構後的版本，註解記錄學到的語法 / STL 用法
```

`ai_optimized.cpp` 只在**自己 AC 之後**才加上，用來對照與學習，不是拿來交題的。
